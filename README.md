# 🕹️ Whack-A-Note
A 2-D whack-a-mole-based rhythm game designed to make rhythm games feel more user-friendly and enjoyable.

## ✨ Key Features
- **Fun Tracks:** Visually appealing tracks with intriguing music—all handmade!
- **Dyslexia Support:** Togglable OpenDyslexic font.
- **Local Custom-Song Creation:** Create your own rhythm!

## 🛠️ Built With
- **Engine:** Unity (V6000.5.4f1)
- **Language:** C#
- **Tools:** PixelStudio, BandLab, GitHub

## 🚀 Getting Started
### Prerequisites
- Unity Hub 3.22.x
- Unity V6000.5.4f1
- GitHub Desktop or GitHub

### Installation / Building
#### Downloading as a ZIP File (For Viewing)
1) Download and Extract
- Go to the ‘WhackANote’ GitHub project page.
- Click the green Code button and select Download ZIP.
- Once downloaded, extract/unzip the archive to a standard folder on your computer.
2) Add to Unity Hub
- Open Unity Hub and select Add project from disk.
- Navigate inside the unzipped folder. Make sure you select the specific folder that contains the Assets sub-folder, then click Add Project.

#### Using GitHub Desktop (Mainly for Collaboration)
1) Clone the Repository
- Go to the GitHub repository page of the project.
- Click the green Code button and copy the URL under the HTTPS tab.
- Open GitHub Desktop
- Go to File > Clone Repository
- Click the URL tab, paste the link, choose a local folder path on your computer, and hit Clone.
2) Add to Unity Hub
- Open Unity Hub.
- Click the Add dropdown button (usually top right) and select Add project from disk.
- Navigate to the folder where you just cloned the repository.
- Select the root folder that contains the Assets, Packages, and ProjectSettings folders, then click Add Project.

#### Setting Up
- In Unity, navigate to the "Menu" Scene (the title screen). This is where you will begin running the game, so please make sure to always start here. Otherwise, the game will not function as intended.
- Click the play button in Unity to begin!

## 🎮 How to Play
- **Navigation:** Simply tap the UI buttons (e.g. Play Button, Settings, Back, Home, Retry, etc).
- **Gameplay:** Tap the moles as well as you can to match the beat. Try to get the best score via different gradings to beat others!
